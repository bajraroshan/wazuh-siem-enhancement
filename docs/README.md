# 📚 Wazuh SIEM Enhancement — Documentation Index

Welcome to the documentation for the **Wazuh SIEM Enhancement Project**.  
This directory contains manuals and guides to install, configure, operate, and extend the enhanced Wazuh SIEM platform.

   - Complete, detailed installation and upgrade manual.

7. `api-integration-guide.md`  
   - Examples for querying enriched alerts and integrating with other tools.
